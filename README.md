# STUDY_BUDDY
Study Buddy is an interactive study planner designed to help students organise their daily routines, manage academic tasks, and stay motivated. It brings useful productivity tools together with a customisable virtual pet companion, making the study experience more engaging and enjoyable.

# 🐾 Study Buddy

A student-friendly study planner with a virtual pet companion.

## Project structure

- `index.html` — page structure and app interface
- `styles.css` — colours, themes, layout, and visual styling
- `script.js` — application behaviour and interactive features

## Run locally

1. Keep all three files in the same folder.
2. Open `index.html` in a modern web browser.
3. An internet connection may be needed for any external libraries or online services used by the app.

## Important note

The JavaScript statements have been kept in their original order during this first structural cleanup to reduce the risk of breaking existing features. The app's Claude-dependent shared-board integration may still require Claude's supported environment and may not work on a normal static GitHub Pages site.

## Publish with GitHub Pages

Upload the contents of this folder to the root of your GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
